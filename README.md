# Arena Showdown: AI Battle Royale

A fast-paced, arcade-style 2D browser shooting game built with HTML5 Canvas, Tailwind CSS, and vanilla JavaScript.

## How to Play

1. **Move:** Use `W`, `A`, `S`, `D` or Arrow Keys.
2. **Aim & Shoot:** Move the mouse cursor to aim, and **Left-Click (hold)** to fire.
3. **Pause / Resume:** Press `P` or `Escape`.
4. **Mute Audio:** Press `M`.
5. **Power-ups:** Collect green glowing drops for Hull Repair (`+`), Shields (`S`), and Rapid-Fire (`»`).

## Running the Game

Simply double-click `index.html` to open and play it instantly in any modern web browser! No installation or server required.
